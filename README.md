## 🚀 วิธีการ Deploy ขึ้นออนไลน์ (ฟรี 100%)

คุณสามารถเลือกวิธีใดวิธีหนึ่งด้านล่างนี้ได้เลยครับ:

### วิธีที่ 1: Deploy ผ่าน GitHub Pages (แนะนำที่สุด ทำได้เลยทันทีใน 1 นาที ✨)
เนื่องจากโปรเจกต์นี้ผูกกับ GitHub ไว้เรียบร้อยแล้ว:
1. เข้าไปที่หน้าคลังเก็บโค้ดของคุณบน GitHub:  
   👉 `https://github.com/sirikorn123/-----------`
2. ไปที่แท็บ **Settings** (เมนูบนสุดของ Repo)
3. เลื่อนลงมาที่เมนูด้านซ้าย เลือก **Pages**
4. ในส่วน **Build and deployment**:
   - **Source**: เลือก `Deploy from a branch`
   - **Branch**: เลือก `main` และโฟลเดอร์เป็น `/ (root)`
5. กดปุ่ม **Save**
6. รอประมาณ 1-2 นาที คุณจะได้ลิงก์เว็บไซต์ HTTPS ฟรี เช่น:  
   `https://sirikorn123.github.io/-----------/`  
   *(สามารถส่งลิงก์นี้ให้เขาได้ทันที!)*

---

### วิธีที่ 2: Deploy ผ่าน Vercel (เร็วและสวยที่สุด)
1. ไปที่ [vercel.com](https://vercel.com) แล้วล็อกอินด้วย GitHub
2. กดปุ่ม **"Add New..."** -> **"Project"**
3. เลือก Repository `-----------` แล้วกด **"Import"**
4. กดปุ่ม **"Deploy"** (ไม่ต้องตั้งค่าอะไรเพิ่มเติม)
5. ภายใน 15 วินาที คุณจะได้ลิงก์ เช่น `https://your-project.vercel.app`

---

### วิธีที่ 3: Deploy ผ่าน Netlify Drop (ลากแล้ววาง)
1. ไปที่ [app.netlify.com/drop](https://app.netlify.com/drop)
2. ลากโฟลเดอร์งานนี้ไปวางในกรอบสี่เหลี่ยมบนหน้าเว็บ
3. ระบบจะสร้างลิงก์เว็บไซต์พร้อมใช้งานให้ทันทีใน 5 วินาที!
